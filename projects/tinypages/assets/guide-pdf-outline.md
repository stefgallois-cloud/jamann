## Comment j'ai sélectionné ces destinations (1 page)

4 critères de sélection :
1. Sécurité pour une femme seule
2. Facilité d'organisation (transports, hébergements)
3. Ambiance favorable aux solos (pas de couples partout)
4. Richesse culturelle ou naturelle exceptionnelle

## Checklist sécurité (1 page)

Avant de partir :
- [ ] Partager son itinéraire avec 2 personnes de confiance
- [ ] Copie numérique de tous ses documents (Drive, email à soi-même)
- [ ] Application Maps.me téléchargée hors ligne
- [ ] Numéro d'urgence du pays sauvegardé
- [ ] Assurance voyage avec assistance rapatriement
- [ ] Pochette anti-RFID pour passeport + carte
- [ ] Réservation première nuit confirmée avant départ

## Bonus — Comment réserver un hébergement solo-friendly (1 page)

3 signes qui indiquent un hébergement accueillant pour les solos :
- Salon commun ou espace de rencontre mentionné dans les avis
- Note "parfait pour les voyageurs solos" dans les commentaires Booking/Airbnb
- Hôte qui répond personnellement aux messages
