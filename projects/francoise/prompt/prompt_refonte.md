# Prompt — Refonte site fd-harmonie.com

## Demande initiale

Voici le site d'une thérapeute : https://www.fd-harmonie.com/

Analyse ce site et réponds à ces 4 questions :

**1. Audit rapide**
- Structure : quelles pages/sections existent ?
- Identité visuelle : couleurs dominantes, style graphique, éléments récurrents (ex : orchidées)
- Ce qui fonctionne bien à garder
- Ce qui est daté, cassé ou peu fonctionnel

**2. Faisabilité pour une freelance no-code**
Je maîtrise : Webflow, Framer, WordPress (Elementor/Divi), Notion + super.so, Softr.
Suis-je en mesure de faire cette refonte seule ? Quel outil me recommandes-tu pour ce type de site vitrine thérapeutique (sobre, élégant, mobile-first) ?

**3. Ce qu'elle veut garder**
La cliente tient à : les orchidées, la palette de couleurs existante (rose, blanc/beige), l'ambiance douce et apaisante.
Comment intégrer ces éléments dans un design plus moderne ?

**4. Plan d'action en 5 étapes**
Donne-moi les 5 étapes concrètes pour mener ce projet de A à Z, de la prise de brief jusqu'à la livraison.

## Résultat
→ Prototype HTML/CSS généré dans `index.html`
→ Couleurs : rose #C9788A · blanc #FFFAF8 · beige #FAF6F2
→ Orchidées SVG intégrées en décoration hero
→ Formulaire de contact + responsive mobile inclus
