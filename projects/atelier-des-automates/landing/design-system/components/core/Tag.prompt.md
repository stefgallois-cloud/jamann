Label de catégorie ou filtre — workflow, outil, thématique.

```jsx
<Tag>Zapier</Tag>
<Tag color="indigo">IA</Tag>
<Tag color="cyan" onRemove={() => {}}>No-code</Tag>
```

Colors: `default` (neutre), `indigo`, `violet`, `cyan`.
`onRemove` ajoute un bouton × pour les tags interactifs (filtres, multi-select).
