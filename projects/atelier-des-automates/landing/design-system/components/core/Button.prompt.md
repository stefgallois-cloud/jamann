Bouton d'action principal — CTA, navigation, formulaires.

```jsx
<Button variant="primary" size="md">Commencer maintenant</Button>
<Button variant="gradient" size="lg">Rejoindre l'atelier →</Button>
<Button variant="secondary">En savoir plus</Button>
<Button variant="ghost">Annuler</Button>
<Button disabled>Indisponible</Button>
```

Variants: `primary` (indigo plein), `secondary` (contour indigo), `ghost` (transparent), `gradient` (indigo→violet).
Sizes: `sm`, `md`, `lg`.
Hover: translateY(-1px) + glow indigo.
