Label de statut, feature flag, ou catégorie — toujours court.

```jsx
<Badge variant="default">No-code</Badge>
<Badge variant="cyan">Nouveau</Badge>
<Badge variant="dark">IA</Badge>
<Badge variant="success">Actif</Badge>
```

Variants: `default` (indigo doux), `violet`, `cyan`, `dark` (sur fond foncé), `outline`, `success`.
Uppercase + letter-spacing large. Ne pas dépasser 3 mots.
