# 📸 Dépose tes images ici

Glisse simplement tes photos dans **ce dossier** avec le **nom exact** indiqué ci-dessous,
puis recharge `index.html` dans le navigateur. La photo apparaît toute seule, en fondu,
par-dessus le placeholder coloré. **Aucun code à toucher.**

## Les 4 images à fournir

| Nom du fichier | Où ça s'affiche | Ratio idéal | Sujet |
|---|---|---|---|
| `story.jpg` | Section « Our Story » (grand visuel) | **4:3** (≈ 800×600) | Photo lifestyle chaleureuse — un chien dans une belle lumière |
| `golden.jpg` | Carte **Golden × Personality** | **3:2** (≈ 600×400) | Golden retriever expressif / attendrissant |
| `frenchie.jpg` | Carte **Frenchie × Coquette** | **3:2** (≈ 600×400) | Bouledogue français, ambiance douce / coquette |
| `memorial.jpg` | Carte **Memorial** | **3:2** (≈ 600×400) | Portrait de chien, lumière douce, sobre et élégant |

## Bon à savoir

- **Formats acceptés** : `.jpg`, `.jpeg`, `.png` ou `.webp` (garde juste le nom : `golden.png` marche aussi).
- **Pas besoin d'être pile aux dimensions** : l'image est recadrée automatiquement (centrée, plein cadre). Respecte juste à peu près le ratio pour éviter un recadrage trop agressif.
- **Poids** : vise < 400 Ko par image pour une page rapide (export « web » / qualité ~80 dans Canva).
- Depuis **Canva** : sélectionne ton visuel → Partager → Télécharger → JPG → renomme avec le nom ci-dessus → dépose-le ici.
