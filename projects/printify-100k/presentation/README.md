# Présentation Bonjour Beasts

**Fichier principal :** `index.html`

## Comment ouvrir / partager

### Option 1 — Ouvrir dans le navigateur
Double-clic sur `index.html` → s'ouvre dans Chrome/Edge/Firefox.

### Option 2 — Envoyer par email
1. Joindre **les 2 fichiers** : `index.html` + `README.md` (optionnel)
2. Le destinataire double-clique sur `index.html` → ça s'ouvre dans son navigateur
3. Pas de dépendance externe sauf la connexion internet pour les fonts Google (sinon la prés s'affiche quand même, juste avec une font système)

### Option 3 — Exporter en PDF
1. Ouvrir `index.html` dans Chrome
2. `Ctrl+P` (ou `Cmd+P` Mac)
3. Destination : **Enregistrer en PDF**
4. Marges : Aucune ou Minimum
5. Cocher **Graphiques d'arrière-plan**
6. Décocher **En-têtes et pieds de page**
7. Enregistrer → tu obtiens un PDF propre prêt à envoyer

### Option 4 — Hébergement web (Netlify Drop, gratuit)
1. Aller sur https://app.netlify.com/drop
2. Glisser le dossier `presentation/` complet
3. Tu obtiens une URL publique en 10 secondes (ex: bonjourbeasts-prep.netlify.app)
4. Partage l'URL à qui tu veux

## Personnalisation rapide

Si tu veux changer le nom du shop (si "Bonjour Beasts" n'est pas dispo) :
- Ouvrir `index.html` dans un éditeur de texte
- `Ctrl+H` (rechercher/remplacer) : `Bonjour Beasts` → `[Ton nouveau nom]`
- Sauvegarder

Si tu veux changer les couleurs :
- Modifier les variables CSS en haut du fichier (lignes 12-22)
- Variables principales : `--sage`, `--cream`, `--rose`, `--charcoal`
