# Protocole validation niche eRank — 30 min

**Quand ?** Avant de publier les 20-50 premiers listings, donc dès que ton compte Etsy + eRank est ouvert.
**Pourquoi ?** Le prompt Niche Validator estime — eRank mesure. Cette étape transforme une hypothèse en certitude.
**Outil :** eRank Basic ($9/mois) — abonnement à activer juste pour cette session, on peut résilier après si besoin.

---

## Pré-requis

- [ ] Compte Etsy ouvert (vendor)

### Critères de validation Check 1

**Pour chaque sous-niche** :

**Si une sous-niche échoue 2/3 critères → la retirer ou la pivoter.**

### Critères Check 2

**Signaux verts** :

### Règles de décision

- **4/4 checks ✅** = GO confident, attaque cette sous-niche en priorité
- **3/4 checks ✅** = GO mais avec un angle sécurisé (creuse une sous-sous-niche)
- **2/4 checks ✅** = MAYBE — soit tu la garde en secondaire, soit tu pivotes
- **<2/4 checks ✅** = NO-GO sur cette sous-niche, remplace par une autre

---

## Action selon le résultat

### Cas A — Les 3 sous-niches passent ≥3/4 checks

🎯 **On lance comme prévu.** La stratégie tient.

### Cas B — 1 sous-niche échoue, 2 passent

🎯 **On garde les 2 qui passent + on pivote la 3ème** sur une alternative du Niche Validator.
Exemples : si Memorial échoue → garder Golden + Frenchie + ajouter "Profession Mom combo" comme 3ème.

### Cas C — 2-3 sous-niches échouent

🎯 **Pivot niche complète.** Run le prompt Niche Validator sur :
1. Profession Mom combo (Boy Mom of 3, Nurse Mom)
2. Cottagecore × mushroom
3. Coquette / soft girl générique

Choisir la niche avec le meilleur score + refaire le protocole eRank dessus.

### Cas D — Tout échoue

🎯 **Stop. Revoir la stratégie.** Probablement signe d'un changement marché qu'on a raté. Re-explorer les niches Etsy bestsellers 2026 via WebSearch + Pinterest Predicts.
