## Principes de base

**1. Le lecteur pense toujours "et alors ?"**
→ Partir du problème client, pas de ta solution.

**2. Concrétiser systématiquement**
→ "Gagner du temps" = nul. "Récupérer 5h par semaine" = percutant.

**3. Un message = une idée**
→ Pas de fourre-tout. Choisir UN angle par contenu.

**4. L'action d'abord**
→ Finir chaque contenu avec une action claire (répondre, cliquer, partager).

## LinkedIn : formats qui marchent

### Post narration (storytelling)
```
[Accroche choc — 1 ligne, sans point de suspension cliché]

[Contexte en 2-3 lignes]

[Le tournant / l'apprentissage]

[Ce que ça change concrètement]

[Question ou CTA final]
```

### Post liste (valeur rapide)
```
[Problème ou affirmation forte]

X [choses/erreurs/astuces] que [audience] devrait savoir :

→ Point 1 (explication courte)
→ Point 2
→ Point 3
[...]

[Conclusion + CTA]
```

### Post cas concret (social proof)
```
[Client/situation fictive ou anonymisée]
Problème : [description]
Ce qu'on a fait : [action]
Résultat : [chiffre ou fait concret]

[Leçon transférable]
[CTA]
```

### Accroches qui fonctionnent
- Chiffre inattendu : "J'ai récupéré 6h par semaine grâce à 3 scénarios Make."
- Contradiction : "J'automatise tout. Mais pas ça."
- Question directe : "Tu passes encore du temps à [tâche répétitive] ?"
- Aveu : "J'ai fait cette erreur 3 fois avant de comprendre."

**À éviter :**
- "Je suis ravi de..." / "Fier d'annoncer..."
- "Dans un monde où..."
- "..." en fin d'accroche

## Email commercial

### Structure AIDA adaptée
```
Objet : [bénéfice ou curiosité — max 50 caractères]

[Accroche : problème connu du destinataire]

[Agitation : ce que ça coûte de ne pas le régler]

[Solution : ce que tu proposes, en 2 lignes max]

[Preuve ou exemple rapide]

[CTA unique et clair]

[Signature courte]
```

### Email de prospection froide (cold outreach)
```
Objet : [prénom], une question rapide

Bonjour [prénom],

J'ai vu que [observation spécifique sur leur activité].

Je travaille avec des [profil similaire] pour [résultat concret].

Est-ce que [problème ciblé] est quelque chose que tu cherches à améliorer ?

Si oui, 20 min cette semaine ?

[Prénom]
```

## Pitch / Proposition commerciale

### Structure en 5 blocs
1. **Situation actuelle** — "Aujourd'hui tu fais X manuellement..."
2. **Impact** — "Ça te coûte Y heures / euros par mois"
3. **Solution** — "Je vais automatiser X avec [outil]"
4. **Livrables** — liste claire et précise
5. **Investissement + next step** — prix, ce qui se passe après le "oui"

### Règle d'or
Ne jamais pitcher sans avoir posé ces 3 questions au client avant :
- Quel est le processus exact aujourd'hui ?
- Combien de temps ça prend ?
- Quel serait le résultat idéal pour toi ?

## Page de vente / Landing page

### Structure minimale qui convertit
```
[Headline : pour qui + résultat]
[Sous-titre : comment + en combien de temps]

[Problème actuel — le client se reconnaît]

[La solution — simple, concrète]

[Ce que tu vas recevoir — liste des livrables]

[Preuve sociale ou garantie]

[Prix + CTA]

[FAQ 3-5 questions]
```
