# Réseaux Sociaux — Optimiser les Ventes

## Principe de base : le tunnel social

Les réseaux ne vendent pas directement — ils créent la confiance.
```
Découverte (reach) → Intérêt (engagement) → Confiance (follows, saves) → Achat (clic lien)
```
→ Chaque plateforme a ses codes, mais ce tunnel est universel.

---

## HOOKS — Stopper le scroll (priorité absolue)

Le hook = les 1 à 3 premières secondes. Si tu rates ça, le reste n'existe pas.
**Règle d'or : le hook doit créer une tension que seule la suite résout.**

### Les 7 types de hooks qui marchent

**1. La promesse de transformation**
```
"Comment j'ai [résultat] en [temps] sans [obstacle]"
"Comment j'ai retrouvé un dos sans douleur en 30 jours sans kiné"
"Comment j'automatise 5h de tâches par semaine en 2 scénarios Make"
```

**2. Le chiffre inattendu**
```
"[X] % des [audience] font cette erreur sans le savoir"
"87% des femmes de 40 ans ont ce problème de dos — et l'ignorent"
"3 modules Make suffisent pour automatiser 80% de ton onboarding client"
```

**3. La contradiction / le paradoxe**
```
"Arrête de [faire quelque chose d'habituel] si tu veux [résultat]"
"Arrête de faire du gainage si tu as mal au dos"
"Plus tu travailles, moins tu gagnes — voilà pourquoi"
```

**4. La question miroir** (le lecteur se reconnaît)
```
"Tu fais encore [action problématique] ?"
"Tu passes encore tes nuits à [tâche répétitive] ?"
"Tu as encore mal au dos le matin en te levant ?"
```

**5. Le secret / l'information cachée**
```
"Ce que [autorité] ne te dit pas sur [sujet]"
"Ce que les kiné ne disent pas sur les hernies discales"
"Ce que les agences ne veulent pas que tu saches sur Make"
```

**6. Le POV / mise en situation** (fort sur TikTok)
```
"POV : tu découvres que [situation problématique]"
"POV : ton client te demande un rapport — tu cliques sur un bouton"
"POV : tu as 45 ans, mal au dos, et tu trouves enfin LA solution"
```

**7. La liste curiosité**
```
"[X] choses que [audience] devrait savoir sur [sujet]"
"5 choses que personne ne dit sur la ménopause et le dos"
"4 automatisations que tout freelance devrait avoir en 2025"
```

- Commencer par "Bonjour" ou se présenter

- Un chiffre banal : "Voici 3 conseils"
- Trop long : si le hook dépasse 8 mots à l'écrit, le couper

## CTA — Quand et comment demander l'action

**Règle : 1 contenu = 1 seul CTA.** Plusieurs CTA = aucun CTA.

### Les CTA par objectif

**Objectif : engagement algorithme** (booste la portée)
```
"Dis-moi en commentaire : [question simple]"
"Enregistre ce post pour y revenir"
"Partage à quelqu'un qui en a besoin"
"Tague quelqu'un qui fait encore ça"
```

**Objectif : récupérer un lead**
```
"Commente [MOT CLÉ] et je t'envoie [ressource] en DM"
"Envoie-moi 'GUIDE' en DM pour recevoir [ressource]"
"Lien dans ma bio pour télécharger [ressource gratuite]"
```

**Objectif : vendre directement**
```
"Lien dans ma bio — [nom du produit] disponible maintenant"
"Clique sur le lien en bio pour accéder au programme"
"[Nom produit] en lien en bio — [prix] seulement"
```

**Objectif : faire suivre le compte**
```
"Suis-moi pour la suite"
"Abonne-toi, je poste [fréquence] sur [sujet]"
```

### Quand mettre un CTA (et quand pas)

✅ Mettre un CTA quand :
- Le contenu apporte de la valeur réelle → les gens veulent "la suite"
- Tu as un produit/ressource directement lié au sujet de la vidéo
- Tu fais une série (CTA = "voir la partie 2")

❌ Ne PAS mettre un CTA quand :
- Le contenu est purement de notoriété / storytelling
- C'est un contenu de réassurance (témoignage, coulisses)
- Le CTA serait forcé ou hors sujet

### Formulation : les détails qui changent tout
- **Spécifique > vague** : "Commente DOS" > "Commente ci-dessous"
- **Actif > passif** : "Clique" > "Tu peux cliquer"
- **Bénéfice inclus** : "Lien en bio pour ne plus avoir mal au dos" > "Lien en bio"
- **Urgence si vraie** : "Disponible jusqu'à dimanche" — jamais de fausse urgence

## INSTAGRAM

### Profil qui convertit
```
Nom : [Prénom] | [Ce que tu fais en 3 mots]
Bio : Pour qui + résultat + preuve de légitimité
CTA : ↓ [action] → lien
Lien : page de vente ou Linktree avec tes produits
```
Exemple pour Dos Libre :
```
Stef | Dos sans douleur après 40 ans
Prothèse lombaire + cervicales → je t'aide à retrouver ton dos
⬇️ Programme gratuit 5 jours
```

### Formats et objectifs

| Format | Objectif | Fréquence idéale |
|--------|----------|-----------------|
| Reels | Découverte (reach) | 3-4/semaine |
| Carrousel | Engagement + sauvegardes | 2-3/semaine |
| Stories | Conversion + lien | Quotidien |
| Post image | Notoriété | 1-2/semaine |
| Live | Vente directe | 1-2/mois |

### Reels qui génèrent des ventes
Structure en 3 temps :
```
0-3s : Accroche choc (= stopper le scroll)
      "Tu fais encore ça avec ton dos ?"
      "Ce que les kiné ne te disent pas"

3-25s : Valeur / démonstration / problème reconnu

Fin : CTA clair
      "Le lien est dans ma bio"
      "Envoie-moi 'DOS' en DM pour recevoir le guide"
```

### Stories qui convertissent
- **J1** : Problème / question à la communauté (poll, quiz)
- **J2** : Ta réponse / ton histoire / la solution
- **J3** : Le produit + lien direct (sticker lien)

→ Jamais vendre en story froide — toujours chauffer avant.

### DM automatisé (ManyChat + Make)
Quand quelqu'un commente un mot-clé (ex : "SURF") → envoi automatique d'un DM avec le lien.
1. Connecter ManyChat à ton compte Instagram
2. Créer un déclencheur : commentaire contient "SURF"
3. Action : envoyer DM avec lien de vente
→ Booste l'algorithme ET convertit sans effort.

## FACEBOOK

### Ce qui marche encore sur Facebook
- **Groupes** : audience ultra ciblée, engagement fort
- **Facebook Ads** : le meilleur outil pub pour cibler précisément
- **Reels Facebook** : portée organique encore bonne
- **Marketplace** : pour certains produits numériques (formation locale)

### Stratégie groupes Facebook
1. Rejoindre les groupes où est ton audience cible
   - Dos Libre : "Mal de dos", "Femmes 40+", "Santé naturelle"
   - Surf Ready : "Surf Maroc", "Débutants surf", "Moniteurs surf"
2. Apporter de la valeur pendant 2-3 semaines (réponses, posts utiles)
3. Partager ton contenu/produit sans spam (règles du groupe)
4. Créer ton propre groupe = actif long terme le plus puissant

### Page Facebook professionnelle
- Moins de portée organique qu'avant
- Utile surtout pour lancer des **pubs Facebook/Instagram**
- Relier à ton compte Instagram (même Business Manager)

### Facebook Ads — structure de base
```
Campagne → Objectif (Trafic / Ventes / Leads)
  └── Ensemble de pubs → Audience + Budget
        └── Pub → Visuel + Texte + CTA
```

**Audiences qui marchent bien pour les produits de Stef :**
- Intérêts : "mal de dos", "yoga", "ménopause", "bien-être femme"
- Lookalike : créer depuis ta liste email ou tes acheteurs existants
- Retargeting : visiteurs de ta page de vente (pixel Facebook à installer)

**Budget pour tester :** 5-10€/jour pendant 7 jours → analyser le coût par clic.

## TIKTOK

### Pourquoi TikTok pour vendre des produits numériques
- Portée organique très forte (même 0 abonnés = peut faire 10k vues)
- Audience 25-45 ans en forte croissance (parfait pour Dos Libre / Reset Ménopause)
- TikTok Shop disponible en France → vendre directement dans l'app

### Profil TikTok optimisé
- Bio : même logique qu'Instagram (pour qui + résultat)
- Lien dans la bio : 1 seul lien (page de vente prioritaire)
- Épingler 3 vidéos : ta meilleure intro + meilleure valeur + produit

### Format vidéo TikTok qui vend
```
0-2s : Accroche visuelle ET textuelle (texte à l'écran dès la 1ère seconde)
       "POV : tu as mal au dos depuis 10 ans"
       "3 erreurs qui empirent ton dos après 40 ans"

2-40s : Valeur rapide, concrète, actionnable
        Montre, démontre, raconte — PAS de théorie

40-60s : CTA
         "Lien dans ma bio pour le programme complet"
         "Commente DOS et je t'envoie le guide gratuit"
```

### Algorithme TikTok — ce qu'il regarde
1. **Taux de completion** : est-ce que les gens regardent jusqu'à la fin ?
2. **Taux de replay** : est-ce qu'ils reviennent dessus ?
3. **Engagement** : likes, commentaires, partages, sauvegardes
4. **Partages** : le signal le plus fort

→ Une vidéo courte vue entièrement > une longue vue à moitié.

### TikTok Shop (vente directe)
1. Créer un compte TikTok for Business
2. Activer TikTok Shop (disponible pour les AE françaises)
3. Ajouter tes produits numériques (PDF, accès app)
4. Tagger les produits dans tes vidéos → achat en 2 clics

## Métriques à suivre

| Métrique | Objectif | Signification |
|----------|----------|--------------|
| Taux de reach | Max | Combien de personnes voient ton contenu |
| Taux d'engagement | >3% | Like + comment + share / reach |
| Taux de clic lien bio | >1% | Combien cliquent vers ta vente |
| Taux de conversion page | 2-5% | Visiteurs → acheteurs |
| Coût par achat (si pub) | < 30% du prix produit | Rentabilité pub |
