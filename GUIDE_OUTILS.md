## 💻 1. Mes Extensions d'Éditeur (Pour Stéphanie)
Ces extensions sont installées dans ton interface Antigravity. Elles fonctionnent en arrière-plan pour te faciliter la vie.

### 🌐 Live Server / Aperçu Web
* **À quoi ça sert ?** Afficher tes sites web en direct (comme celui de Françoise Davenas) à côté de ton code.
* **Comment l'utiliser ?** Clique sur l'icône de **Navigateur/Globe** dans la barre d'Antigravity, ou saisis l'adresse suivante dans la barre de recherche du navigateur intégré :
  `file:///C:/Users/DELL/Desktop/test claude/projects/francoise/index.html`

### 🎨 Prettier
* **À quoi ça sert ?** Aligner, espacer et ranger ton code HTML/CSS automatiquement pour qu'il soit impeccable.
* **Comment l'utiliser ?** **100 % automatique.** Fais simplement `Ctrl + S` pour sauvegarder ton fichier, et le code se range tout seul !

### 🏷️ Auto Rename Tag
* **À quoi ça sert ?** Renommer automatiquement la fin d'une balise HTML quand tu modifies le début.
* **Comment l'utiliser ?** **100 % automatique.** Rien à faire, cela évite les bugs d'affichage.

## 📚 2. Catalogue des meilleures extensions à installer (Traduit en Français)
Voici ton catalogue pour choisir tes extensions en toute simplicité. Tu as juste à **copier le nom en anglais**, le chercher dans ton panneau d'extensions, et cliquer sur le bouton bleu **Install**.

### 🌟 Les Indispensables (À installer en priorité)
1. **`Live Server`** :
   * *Rôle en français :* L'aperçu en direct. Permet de voir tes pages web s'actualiser instantanément dans le navigateur dès que tu fais une modification.
2. **`Prettier - Code Formatter`** :
   * *Rôle en français :* Le rangement automatique de ton code. Remet tout au propre (alignements, espaces) à chaque sauvegarde.
3. **`Auto Rename Tag`** :
   * *Rôle en français :* Le renommeur de balises HTML. Change automatiquement la balise fermante si tu modifies la balise ouvrante.

### 🎨 Design & Confort Visuel
4. **`Color Highlight`** :
   * *Rôle en français :* Le surligneur de couleurs. Surligne visuellement tous les codes couleurs de ton fichier CSS avec leur vraie couleur pour t'aider à concevoir tes palettes graphiques.
5. **`Image Preview`** :
   * *Rôle en français :* L'aperçu d'images dans le code. Affiche une toute petite icône (miniature) dans la marge de ton code à côté de tes liens d'images (comme ton orchidée). Très pratique pour savoir quelle image est insérée à quel endroit !

### ⚡ Vitesse & Raccourcis
6. **`Path Intellisense`** :
   * *Rôle en français :* L'aide aux chemins de fichiers. Quand tu tapes un lien (comme `images/` ou `soins/`), il te propose automatiquement la liste des fichiers disponibles pour t'éviter d'écrire le mauvais nom et d'avoir une image cassée.
7. **`HTML CSS Support`** :
   * *Rôle en français :* L'aide au style CSS. Quand tu écris ton code HTML, il te suggère automatiquement les classes CSS de ton projet pour t'éviter de faire des fautes de frappe.
